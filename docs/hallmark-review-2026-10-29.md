# Hallmark 优化与验证记录

日期：2026-10-29

依据：[Nutlope/Hallmark](https://github.com/Nutlope/hallmark) 的 redesign、editorial 和 finish-review 指引。沿用项目既有的暖纸色、陶土色与衬线标题，调整信息层次、阅读节奏与交互反馈。

## 实现范围

- 首页重新组织为作品目录、文章索引和资源列表；统一页面宽度、留白与元信息字号，减少装饰符号。
- 作品、文章、资源、提示词、实验室、关于、剪报、分类和搜索页统一阅读样式，补齐空状态入口与移动端描述。
- 搜索结果移除嵌套链接，增加原生 GET 搜索表单，保留独立分类入口和结果数量提示。
- 公共导航增加跳转正文、菜单 Escape 关闭与焦点恢复；资源子页显示所属导航状态。
- 提示词复制补齐等待、成功、失败重试与读屏反馈；正文可展开、选择和滚动。
- 登录表单补齐空值和错误反馈、输入关联与忙碌状态；保存确认框在请求期间防止误关闭。
- 后台导航改善当前页面判断、长名称和短屏滚动。公众号预览简化外框，保留发布画布；编辑器焦点轮廓立即呈现。
- 浅色焦点环由实测不足 3:1 的颜色调整为更深的蓝色；资源分类标签修复旧选择器覆盖后，浏览器实测为 14px。

## Hallmark 检查的实际结果

没有将 Hallmark 的启发式扫描描述为全绿：

- 包含原有共享样式的静态扫描：**0 FAIL、1 REFLEX、7 WARN**，另有已说明的旧工作台密度例外。
- 首页、作品、提示词、搜索四个 URL 的完整渲染扫描：**0 FAIL、3 REFLEX、0 WARN**。
- 渲染层三项提示均为 320 / 375px 搜索结果中的长文章标题换行。标题是内容，保留完整文本；不通过截断或强制单行规避规则。
- 静态 REFLEX 是公众号发布预览的纯白画布。它用于还原目标平台，独立于 Studio 的暖纸色界面。
- 其余静态 WARN 涉及既有引用边线、继承文字颜色、短说明宽度及把空状态误识别为大数字的启发式规则。已结合实际明暗主题和响应式截图复核。
- 首屏采用较短的文字 Banner，使作品目录尽早出现；保留品牌配色与后台既有紧凑密度的理由已写在样式注释中。

## 数据与发布边界

验证数据和临时认证信息位于仓库外的隔离环境。没有修改生产 D1、数据库结构、鉴权 API 或公开/私有发布规则。测试生成的既有截图已恢复，临时审查产物与本地配置不纳入提交。

本次验证包含 Next.js 生产构建，不包含 Cloudflare 部署；未推送远端或发布站点。
